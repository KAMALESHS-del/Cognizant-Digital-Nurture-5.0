

Generative AI (GenAI) is one of the most important technologies in today's software industry. It is widely used for **content creation, programming assistance, chatbots, image generation, video generation, and automation**. Companies like **Microsoft, Google, Amazon, Cognizant, Infosys, TCS, and Accenture** use Generative AI in their products and services.

---

# What is Generative AI?

## Definition

**Generative AI (GenAI)** is a type of **Artificial Intelligence (AI)** that can **generate new content** such as:

* Text
* Images
* Audio
* Video
* Code
* Music

Unlike traditional AI, which mainly **analyzes or classifies existing data**, Generative AI creates **new and original outputs** based on patterns learned from large datasets.

---

## Real-Life Example

Suppose you ask an AI:

> "Write a leave application."

Generative AI creates a **new leave application**.

Or you ask:

> "Generate Python code to sort a list."

Generative AI writes the code automatically.

# Traditional AI vs Generative AI

## Traditional (Discriminative) AI

### Definition

Traditional AI is designed to:

* Analyze data
* Classify data
* Predict outcomes
* Recognize patterns

It **does not create new content**.

---

## Examples

* Spam Email Detection
* Face Recognition
* Credit Card Fraud Detection
* Disease Prediction
* Weather Forecasting

---

## Example

Input:

```text
Email
```

Traditional AI

↓

Predicts

```text
Spam
```

or

```text
Not Spam
```

---

# Generative AI

### Definition

Generative AI creates **new content** instead of only making predictions.

---

## Example

Input


A completely new story.

# 1. Early Chatbots (1960s)

One of the earliest chatbots was **ELIZA**, developed in 1966.

It simulated conversations using simple pattern matching.

---

## Example

User

```text
I feel sad.
```

ELIZA

```text
Why do you feel sad?
```

It did **not understand meaning**; it matched patterns in the input.

---

# 2. Machine Learning Era (1980s–1990s)

AI systems became better at:

* Learning from data
* Pattern recognition
* Classification
* Prediction

However, they still could not generate high-quality content.

---

# 3. GANs (2014)

**Generative Adversarial Networks (GANs)** were introduced in 2014.

A GAN has:

* Generator
* Discriminator

The Generator creates fake content.

The Discriminator checks whether it looks real.

Both improve through competition.

---

## Applications

* Image Generation
* Face Generation
* Style Transfer
* Art Creation

---

# 4. Transformer Architecture (2017)

Google introduced the **Transformer** architecture in 2017.

It greatly improved:

* Language understanding
* Translation
* Text generation

Modern large language models (LLMs) are based on Transformers.

---

# 5. GPT-3 (2020)

**GPT-3** was released in 2020.

It demonstrated impressive capabilities in:

* Writing
* Translation
* Coding
* Question answering
* Summarization

---

# 6. ChatGPT (2022)

**OpenAI>'s **ChatGPT** was launched in 2022.

It made conversational AI widely accessible.

Capabilities include:

* Natural conversations
* Code generation
* Learning assistance
* Report writing
* Brainstorming

---

# 7. GitHub Copilot and Beyond

Modern AI coding assistants include:

* **Claude**

They help developers:

* Write code

# Limitations of Generative AI

* Can produce incorrect information ("hallucinations")
* May generate biased content
* Requires human review
* Can make factual or coding mistakes
* Depends on the quality of prompts
* Raises privacy and copyright considerations

# Cognizant Technical Assessment – Important Questions

### 1. What is Generative AI?

**Answer:** Generative AI is a type of artificial intelligence that creates new content such as text, images, code, audio, and videos by learning patterns from large datasets.

---

### 2. How is Generative AI different from Traditional AI?

| Traditional AI          | Generative AI               |
| ----------------------- | --------------------------- |

### 3. Name four applications of Generative AI.

**Answer:**

* Text generation
* Code completion
* Image creation
* AI chatbots

---

### 4. What are GANs?

**Answer:** GANs (Generative Adversarial Networks) are deep learning models introduced in 2014 that generate realistic content using two competing neural networks: a Generator and a Discriminator.

---

### 5. What is ChatGPT?

**Answer:** ChatGPT is an AI chatbot developed by OpenAI that generates human-like responses, assists with coding, writing, learning, summarization, and problem-solving.

---

### 6. What is GitHub Copilot?

**Answer:** GitHub Copilot is an AI-powered coding assistant that suggests code, functions, comments, and documentation while developers write software.
